Two notes on this index

The numbering has one collision. Both the Golden Rules and the Scanner Filter Map are filed as 25 in docs/; the Scanner Filter Map is marked 25* here. Renumbering would break the filename links, so it is flagged rather than fixed.

Each page keeps its own address. The three published documents are separate pages with their own URLs, so any link you have already shared or bookmarked still works — this library indexes them, it does not replace them.
